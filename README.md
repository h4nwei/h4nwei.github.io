# Personal Website

http://h4nwei.github.io/

## Structure

- `index.html`: Homepage (about, news, selected publications).
- `publications.html`: Full publication list with filters.
- `lab.html`: Lab page (openings and members).
- `publications.js`: Publication data source.
- `data/news.json`: News data source.
- `data/lab.json`: Lab openings and members data source.
- `js/navigation.js`: Shared top navigation.
- `js/news.js`: News loader for homepage.
- `js/publications-render.js`: Publication renderer for homepage and publications page.
- `js/lab.js`: Lab page loader and renderer.
